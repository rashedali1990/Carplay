# CarPlay PhoneCast - iPhone & Apple CarPlay Suite with Android Car Screen APK

تطبيق متكامل لعرض محتوى وبث شاشة iPhone على شاشة السيارة عبر **Apple CarPlay**، مع حزمة **APK** خاصة بشاشات السيارات التي تعمل بنظام Android.

## 🚀 روابط التنزيل المباشر (Direct Downloads)
- **ملف الـ APK لشاشات السيارات والأندرويد:** [`CarPlayPhoneCast.apk`](/CarPlayPhoneCast.apk)
- **حزمة كود Xcode الكاملة للآيفون (ZIP):** [`CarPlayPhoneCast_Xcode_Project.zip`](/CarPlayPhoneCast_Xcode_Project.zip)

## 📦 التنزيل والاستنساخ عبر GitHub (Clone via Git)
```bash
# استنساخ المشروع كاملاً إلى جهازك
git clone https://github.com/YOUR_USERNAME/carplay-phonecast.git

# الدخول للمجلد
cd carplay-phonecast

# تثبيت الحزم وتشغيل المنصة محلياً
npm install
npm run dev
```

## 📤 كيفية رفع المشروع إلى حسابك على GitHub في ثوانٍ:
```bash
# 1. إنشاء مستودع جديد على GitHub باسم carplay-phonecast
# 2. ربط المستودع ورفعه:
git remote add origin https://github.com/YOUR_USERNAME/carplay-phonecast.git
git branch -M main
git push -u origin main
```
